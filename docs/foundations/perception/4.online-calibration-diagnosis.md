# 在线标定、评测与故障诊断

在线标定应被视为受控发布流程：先筛选数据和场景，再预览，确认后执行，最后回查结果文件、版本和代表性样本。单独的进程成功、HTTP 200 或 `kSuccess` 都不能替代结果质量检查。

```mermaid
flowchart LR
  D[数据/场景筛选] --> V[Preview]
  V --> E[确认后 Execute]
  E --> R[结果与版本回查]
  R --> H[指标/健康检查]
  H -->|异常| B[回滚]
```

建议持续记录消息频率、丢包率、时间偏移、静止均值、融合残差和温度。低收敛、无代表结果、输入时间异常分别对应数据门槛、质量门槛和时间链路问题。

练习：为仿真系统注入外参漂移和延迟，设计告警阈值，并实现“告警—降级—回滚”的状态机。
