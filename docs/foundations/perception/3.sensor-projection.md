# 相机、LiDAR 与 IMU 的外参与投影

相机内参决定“怎么成像”，外参决定“传感器在哪里”。LiDAR 点投影到图像前，必须先完成 LiDAR→机身→相机的变换，再应用内参和畸变模型。

$$p_B=R_{BA}p_A+t_{BA},\qquad u\sim Kp_C$$

固定 yaw 误差 $\delta$ 会造成约 $d\tan\delta$ 的横向误差，因此远处目标更适合用来暴露外参问题。检查时应同时覆盖近、中、远距离和不同俯仰角。

常见症状：整体平移优先查平移量和单位；左右翻转查轴约定或变换方向；边缘发散查畸变参数；只在运动中错位查时间偏移。

练习：用 NumPy 生成棋盘格和 LiDAR 平面，注入 1° yaw 误差，画出投影偏差随距离的曲线。
